# A first-try pass outranks a leftover drill entry

Learner progress once kept a failed-command list and a separate per-Task record, and a hand-edited or half-migrated file could hold both for the same Task. Opening the file now rewrites it into one history. A first-try pass wins, so that Task leaves Due Review and the failed-command drill. A drill entry with no pass record becomes a Task with no first-try pass whose next review time has arrived.

The other choice was to let the drill entry win, clearing the first-try pass and making the Task due now. Only a first-try pass removes a Task from Review, so the pass is the stronger fact, and the rewrite keeps that true on an old file.
